# Kế toán nhanh AZ – Website dịch vụ kế toán hộ kinh doanh

Website tĩnh giới thiệu dịch vụ kế toán, kê khai thuế cho hộ kinh doanh và phần mềm MISA
(eShop, meInvoice, eSign, AMIS Kế toán HKD).

- Mã nguồn website: [`docs/`](docs/)
- Quy tắc & kiến trúc dự án: [`.claude/CLAUDE.md`](.claude/CLAUDE.md)

## Chạy thử

Mở `docs/index.html` bằng trình duyệt. Không cần cài đặt hay build.

## Đưa lên mạng

- **GitHub Pages**: Settings → Pages → nhánh `main`, thư mục `/docs`.
- **Hosting khác**: tải toàn bộ nội dung thư mục `docs/` lên thư mục gốc của hosting.
